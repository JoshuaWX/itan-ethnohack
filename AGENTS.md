# EthnoHack working agreements

This repository supports EthnoHack 2026, Track 4: Digital Health & Phytotherapy,
November 2–8, 2026. The project idea and stack remain undecided.

Before substantial work:
1. Read `docs/PROJECT_BRIEF.md` and `docs/PROGRESS.md`; read task-relevant notes
   linked from `docs/README.md` to establish goals, constraints, and current state.
2. Identify the requested work and inspect installed skill names/descriptions in
   `.agents/skills/` and `docs/SKILLS.md`. Load the smallest relevant combination,
   then follow those instructions only where applicable. Prefer repository copies
   when an identically named personal skill exists; do not load both.
3. Use `ethnohack-workflow` for Track 4 evidence, research-to-engineering planning,
   ML suitability, scientific validation, or milestone coordination. Routine edits
   can proceed directly. Skill selection is contextual, not guaranteed.
4. Carry out the authorized task. Choose the simplest scientifically valid method;
   skill availability alone never justifies ML, deep learning, or a framework.
5. Run proportionate tests and scientific checks. Distinguish observed results
   from plans and untested assumptions. Record material decisions in
   `docs/DECISIONS.md`, findings in the relevant note, and status in `docs/PROGRESS.md`.

Apply `docs/SCIENTIFIC_EVIDENCE.md` to scientific claims and outputs, and
`docs/DATA_SOURCES.md` before acquiring or processing data. The prototype is for
research and demonstration, never a validated clinical decision-support system.

Review third-party scripts before execution. Skill installation does not authorize
dependency installation, bulk retrieval, paid services, credential access, uploads,
or deployment. Translate shell examples to native PowerShell as needed. Ask before
administrative or potentially disruptive changes. Keep secrets and identifiable
health data out of Git, prompts, research notes, and external services.

Codex Desktop is primary; Codex CLI and WebStorm are secondary interfaces. Preserve
existing user configuration. Do not install or configure Claude Code tooling.
