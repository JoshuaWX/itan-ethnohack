# EthnoHack research vault

Use this directory as the Obsidian vault. Relative Markdown links work in Obsidian,
WebStorm, and GitHub. Unknown information stays **TBD** until supported.

- [Project brief](PROJECT_BRIEF.md): confirmed context, open questions, scope.
- [Research findings](RESEARCH_FINDINGS.md): search records and synthesis.
- [Expert interviews](EXPERT_INTERVIEWS.md): consent, questions, attributed notes.
- [Data sources](DATA_SOURCES.md): provenance, authorization, quality.
- [Scientific evidence](SCIENTIFIC_EVIDENCE.md): evidence and safety standards.
- [Architecture](ARCHITECTURE.md): options and eventual system boundaries.
- [Development plan](DEVELOPMENT_PLAN.md): proposed one-week milestones.
- [Decisions](DECISIONS.md): decision record and rationale.
- [Progress](PROGRESS.md): actual status, next actions, blockers.
- [Skills](SKILLS.md): installed inventory and task selection.
- [Setup](SETUP.md): tool versions, commands, verification, remaining actions.

Keep patient information, identifiable interview transcripts, credentials, and
restricted datasets outside this vault and repository. No community plugins were
installed; local Obsidian plugin settings are excluded from Git.
